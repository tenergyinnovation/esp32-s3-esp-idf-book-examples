# บทที่ 1 รู้จัก ESP32-S3 และบอร์ด DevKitC-1

ตัวอย่างประกอบบทที่ 1 ของหนังสือ

## หัวข้อในบท

1.1 ESP32-S3 คืออะไร: สมองของอุปกรณ์ IoT  
1.2 เทียบ ESP32-S3 กับ ESP32-C3 และ ESP32 รุ่นแรก  
1.3 ข้างในชิป: 2 core, ROM, SRAM, PSRAM, Flash  
1.4 บอร์ด DevKitC-1 N16R8: ปุ่ม, LED, พอร์ต USB สองช่อง  
1.5 ขา GPIO, แรงดัน 3.3 V และขาที่ห้ามใช้ (GPIO35–37)  
1.6 Strapping pins และ boot mode  
1.7 รู้จัก Wokwi: บอร์ดจำลองบนคอมพิวเตอร์

## ตัวอย่าง

| โฟลเดอร์ | สิ่งที่ทำ | รัน | สถานะ |

| `act01_board_inspection` | กิจกรรม: ตรวจบอร์ดจริง อ่านชื่อโมดูล และหาตำแหน่งปุ่ม/LED | บอร์ดจริงเท่านั้น | กิจกรรมในหนังสือ |
| `act02_pin_map_quiz` | กิจกรรม: หาขาที่ใช้ได้และขาที่ห้ามใช้จากแผนผังขา | — | กิจกรรมในหนังสือ |
| `act03_wokwi_first_look` | กิจกรรม: เปิดโปรเจกต์ Wokwi ตัวอย่างและกด Start | Wokwi + บอร์ดจริง | กิจกรรมในหนังสือ |
