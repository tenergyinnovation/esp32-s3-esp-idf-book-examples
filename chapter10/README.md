# บทที่ 10 Wi-Fi, IP Network และ Time Sync

ตัวอย่างประกอบบทที่ 10 ของหนังสือ

## หัวข้อในบท

10.1 Wi-Fi ใน ESP-IDF ทำงานอย่างไร  
10.2 เชื่อมต่อ Wi-Fi (station)  
10.3 ต่อใหม่แบบ exponential backoff  
10.4 SoftAP: บอร์ดปล่อย Wi-Fi เอง  
10.5 สแกน Wi-Fi และอ่านความแรงสัญญาณ  
10.6 SNTP: รู้เวลาจริง  
10.7 HTTP server: หน้าเว็บสถานะ
