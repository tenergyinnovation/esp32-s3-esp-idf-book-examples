# บทที่ 12 Bluetooth Low Energy และ Provisioning

ตัวอย่างประกอบบทที่ 12 ของหนังสือ

## หัวข้อในบท

12.1 BLE ทำงานอย่างไร  
12.2 ประกาศตัว (advertising)  
12.3 GATT server: characteristic แบบอ่านได้  
12.4 Notify: ส่งค่าให้เองเมื่อมีค่าใหม่  
12.5 Write: สั่งงานจากมือถือ  
12.6 Wi-Fi provisioning ผ่าน BLE
