# บทที่ 17 USB และจอแสดงผล: ความสามารถพิเศษของ ESP32-S3

ตัวอย่างประกอบบทที่ 17 ของหนังสือ

## หัวข้อในบท

17.1 USB บน ESP32-S3  
17.2 USB CDC: พอร์ต COM เสมือน  
17.3 USB HID: บอร์ดเป็นคีย์บอร์ด  
17.4 USB MSC: บอร์ดเป็นแฟลชไดรฟ์  
17.5 เอฟเฟกต์ RGB: วงล้อสี HSV  
17.6 กราฟิกบน OLED

## ตัวอย่าง

| โฟลเดอร์ | สิ่งที่ทำ | รัน | สถานะ |
|---|---|---|---|
| `ex01_usb_cdc` | Serial ผ่าน USB OTG | บอร์ดจริงเท่านั้น | [เปิด](ex01_usb_cdc/) |
| `ex02_usb_hid_keyboard` | กดปุ่มแล้วพิมพ์ข้อความลงคอมพิวเตอร์ | บอร์ดจริงเท่านั้น | [เปิด](ex02_usb_hid_keyboard/) |
| `ex03_usb_msc` | ให้คอมพิวเตอร์เห็นบอร์ดเป็นไดรฟ์ | บอร์ดจริงเท่านั้น | [เปิด](ex03_usb_msc/) |
| `ex04_rgb_led_effects` | เอฟเฟกต์ไฟ RGB | Wokwi + บอร์ดจริง | [เปิด](ex04_rgb_led_effects/) |
| `ex05_oled_graphics` | กราฟิกบน OLED: เกจ กราฟ แอนิเมชัน | Wokwi + บอร์ดจริง | [เปิด](ex05_oled_graphics/) |
