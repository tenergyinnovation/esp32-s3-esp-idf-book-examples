# ex03_usb_msc

**บทที่ 17** · ทำให้บอร์ดเป็น "แฟลชไดรฟ์" (USB Mass Storage)

## รันบนบอร์ดจริง

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbserial-XXXX flash monitor   # ออก: Ctrl + ]
```

> ตัวอย่างนี้ต้องใช้บอร์ดจริง

## ผลที่คาดหวัง (Serial Monitor)

```text
I (...) msc: เสียบพอร์ต USB แล้วจะเห็นไดรฟ์ใหม่ (7168 KB)
I (...) msc: ตอนนี้ไดรฟ์เป็นของ: คอมพิวเตอร์
I (...) msc: ตอนนี้ไดรฟ์เป็นของ: โปรแกรม (/data)
I (...) msc: เขียน /data/log.txt แล้ว
```

## หมายเหตุ

- ต่อสาย USB-C **สองเส้น**: พอร์ต **UART** (ดู log และ flash) กับพอร์ต **USB** (GPIO19/20 ซึ่งเป็นอุปกรณ์ USB ที่เราสร้าง) เมื่อ TinyUSB เริ่มทำงาน พอร์ต USB จะไม่เป็น USB-Serial-JTAG อีกต่อไป จึงต้อง flash ผ่านพอร์ต UART
- Wokwi ยังจำลองอุปกรณ์ USB (TinyUSB) ไม่ได้ ตัวอย่างนี้ต้องทดลองกับบอร์ดจริง
- ครั้งแรก คอมพิวเตอร์อาจถามให้ฟอร์แมตไดรฟ์ ให้ฟอร์แมตเป็น FAT (MS-DOS)
- ก่อนกดปุ่มให้โปรแกรมใช้ ควร "Eject" ไดรฟ์บนคอมพิวเตอร์ก่อน เพื่อให้ข้อมูลที่ค้างใน cache ถูกเขียนลงจริง
